# Security Policy

## Reporting a Vulnerability

If you believe you've found a security vulnerability in this project, please report it through one of these channels:

- **Email:** [security@airtable.com](mailto:security@airtable.com)
- **HackerOne:** [hackerone.com/airtable](https://hackerone.com/airtable?type=team)

Please do not open a public GitHub issue for security vulnerabilities.

## Scope

This policy covers the CLI client code in this repository. Issues with the Airtable MCP server or Airtable platform should be reported through the same channels above.
